# Fabless Intership Project

TOPST(D3-G, VCP-G, AI-G) 플랫폼을 기반으로 차량용 SoC 개발 환경을 구성하고, FreeRTOS를 적용하여 동작을 검증합니다.

## 활동 내역
- WSL2 및 Ubuntu 기반 Linux 개발 환경 세팅
- 크로스 컴파일 툴체인 및 `FreeRTOS-VCP` 프로젝트 구성
- Git / GitHub을 활용한 환경 세팅 및 실습 기록 관리
